LAST LANTERN — CLASS ART NOTES

Created with the built-in imagegen tool using the user's reference sheets. No external runtime services are used.

The armed-heroes folder contains 31 complete hero-and-weapon sprites. Fingers, arms and weapon grips are drawn together in each image. They replace the separate equipment overlay for every selectable weapon. Runtime pose atlases animate these composed sprites using leg articulation, body anticipation/recoil, dash lean and skill lift; these are procedural pose frames, not separately hand-painted animation frames.

class-weapons: 25 new reference-inspired inventory weapon sprites.
class-heroes: six unarmed body reference sprites.
chapter-enemies: 12 new enemy/boss sprites for chapters 2 and 3.
class-effects: six skill effects and six dash streaks.
armed-heroes: current complete armed variants and source strips.
The older animations folder records the previous edition's exported frames; the current game bakes its own updated pose frames offline.
